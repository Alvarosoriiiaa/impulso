# Impulso — versión web de prueba

Versión web, pensada para móvil, de Impulso: frases motivacionales a pantalla completa, cuestionario de bienvenida, sección «Para ti», seguimiento del objetivo, temas y favoritas.

Ábrela en el iPhone y usa *Compartir › Añadir a pantalla de inicio* para tenerla como una app.

Los recordatorios y los widgets solo están en la app nativa de iPhone.
